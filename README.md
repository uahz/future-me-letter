## 功能

- **表单输入**：年龄、职业/身份、近期困扰、近期小确幸
- **时长选项**：5 年 / 10 年 / 20 年，决定未来信的时间跨度和内容深度
- **四种语气**：
  | 语气 | 调性 | 适用场景 |
  |---|---|---|
  | 温和 | 温柔、鼓励、理解 | 想被安慰时 |
  | 犀利 | 直白、不废话、穿透 | 需要被点醒时 |
  | 诗意 | 文艺、意象、留白 | 想要仪式感时 |
  | 朋友 | 轻松、幽默、无距离 | 想要轻松一封信时 |
- **内置模板引擎**：每种语气 2-3 套开场白、正文、结尾随机组合，每次生成不完全一样
- **下载卡片**：竖版 810×1080 PNG，信纸质感 + 朱砂印章
- **复制文字**：纯文本格式，方便粘贴到笔记/朋友圈
- **历史记录**：自动保存最近 5 封，可随时重读
- **无 API**：所有模板本地生成，无需网络，无需 API key

## PWA

- manifest.json：配置名称、图标、主题色、竖屏锁定、独立窗口
- Service Worker：注册即缓存，断网也能开

## 安装使用

### PC

直接在浏览器打开 index.html。推荐用 Edge / Chrome 地址栏右上角的「安装」按钮，添加为独立窗口应用。

### Android（PWA 安装）

`ash
# 在项目目录启动本地服务器
python -m http.server 8765

# 或
npx serve -p 8765
`

1. 手机通过同一局域网访问 http://你的IP:8765
2. Chrome 菜单 → 添加到主屏幕
3. 桌面出现图标，打开后无浏览器栏

### 离线

首次访问后 Service Worker 自动缓存，断网时重新打开仍能正常使用。

## 技术栈

| 层 | 选用 |
|---|---|
| HTML 模板 | 纯手工 |
| 样式 | 原生 CSS（变量 + 媒体查询） |
| 模板引擎 | JavaScript 对象驱动（8 套模板 × 3 段式拼配） |
| 卡片渲染 | Canvas 2D API |
| 持久化 | localStorage（自动存 5 封历史） |
| PWA | manifest.json + Service Worker（Cache First） |
